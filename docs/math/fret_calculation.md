# Fret Calculation

## Formula

Remaining scale:

L_remaining = L / 2^(n/12)

Distance from nut:

L_distance = L - L_remaining

Where:

L = Scale length

n = Fret number

| Fret | Distance (609.6 mm scale) |
| ---: | ------------------------: |
|    1 |                 34.214 mm |
|    2 |                 66.507 mm |
|    3 |                 96.987 mm |
|  ... |                       ... |
|   12 |                304.800 mm |
